# Figure provenance

This note maps each figure in the manuscript to its data, design-rendering code
and embedded raster. The manuscript is the authority for the final appearance:
most rasters were assembled or re-encoded by the authors from the design
renders, so a re-render reproduces the plotted quantities and the design, but
not necessarily the exact PNG bytes. Two of them — Figures 5 and 7 — now are
regenerated byte for byte; the measured agreement for every figure is at the
end of this note.

## What each level of reproduction gives

- **Plotted values.** Fully reproducible from the archived arrays and JSON
  files listed above. The numeric anchors are recorded in the per-figure
  READMEs and in the scripts' `[verify]`/print output.
- **Design layout.** Reproducible by running the script, for every figure with
  a script — that is, all except Figure 1, which is a hand-drawn schematic.
  Measured against the embedded rasters (same canvas, both flattened onto
  white, per-channel maximum absolute difference):

  | figure | pixels identical | mean \|Δ\| per channel, /255 |
  |---|---|---|
  | 2 | 92.45 % | 5.70 |
  | 3 | 91.88 % | 2.75 |
  | 4 | 96.79 % | 1.43 |
  | 5 | 100.00 % | 0.00 |
  | 6 | 91.00 % | 4.66 |
  | 7 | 100.00 % | 0.00 |

  "Identical" means every channel of the pixel is equal; the two images are
  flattened onto white first, so an alpha channel does not count as ink in one
  and not the other.

- **Exact PNG bytes.** Guaranteed for Figures 5 and 7, whose archived packages
  regenerate the embedded raster byte for byte (md5 for md5). Every other raster
  was author-assembled or re-encoded and may differ in font rasterisation,
  canvas size or encoding.

## Running the scripts from a clone

Every reproduction script resolves its inputs and outputs relative to its own
directory, so from a clone each one is just:

| figure | command (from the repository root) | writes | packages |
|---|---|---|---|
| 2 | `python figures/figure_code_20261006/Figure2_eight_property_comparison/fig2_plot.py` | `results/fig2_eight_property.png` | numpy, matplotlib |
| 3 | `python figures/figure_code_20261006/Figure3_baseline_comparison/fig3_plot.py` | `results/fig3_baseline_profile.png` | numpy, matplotlib |
| 4 | `python repro/fig4_zeroed_20261021/fig4_plot_manuscript.py` | `results/fig4_manuscript.png` | numpy, matplotlib, pillow |
| 5 | `python repro/fig5_recompute_20261114/fig5_docx.py` | `results/fig5_docx.png` | numpy, matplotlib |
| 6 | `python figures/figure_code_20261006/Figure6_tmQMg_cross_protocol/fig6_plot.py` | `results/fig6_cross_protocol.png` | numpy, matplotlib |
| 7 | `python repro/fig7_r26_20261115/fig7_plot.py` | `results/fig7_new.png`, `results/fig7_old_check.png` | numpy, matplotlib |

Figure 1 has no script (hand-drawn). Figure 4 additionally needs its two
archived `.npz` result files, and its checkpoints are release assets — see
`repro/fig4_zeroed_20261021/README.md`.
