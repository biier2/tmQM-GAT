# Figure revision notes (archive)

Verbatim copies of the figure documentation as it stood on 2026-11-16, before the
active READMEs were condensed to reproduction-only content. Nothing was edited on
the way in except a banner at the top of each file.

These files hold what the active READMEs no longer carry:

- the advisor's comments, quoted verbatim
- the item-by-item mapping from each comment to the script line that implements it
- draft-to-draft image comparisons (final draft vs the advisor's draft)
- version timelines with the md5 of every intermediate raster
- pixel-verification records
