# data_indices — split and index files

Small NumPy/JSON records that define the cohorts, splits, and analysis subsets used in the paper. All arrays are integer indices or boolean masks unless noted. Index conventions follow the corresponding generating scripts.

| File | Contents |
|---|---|
| `ensemble_split.npz` | Main-domain split (90,317 complexes): `te_idx` (13,547) fixed test set, `cv_idx` (76,770) cross-validation pool, `fold_{0,1,2}_train` (51,180) / `fold_{0,1,2}_val` (25,590) — KFold(3, shuffle, seed 42). |
| `ensemble_split_new.npz` | Updated-domain split (90,377 complexes, element-preserving-isomorphism domain): `te_idx` (13,556), `cv_idx` (76,821), `fold_{0,1,2}_train` (51,214) / `fold_{0,1,2}_val` (25,607). Used by the corrected-domain ensembles and the geometry-aware baselines. |
| `gating_indices.npz` | Split-conformal calibration/gating records computed from ensemble test predictions (see `analysis/s4_conformal.py` and `repro/round8_recon_20261015/recon_conformal_gating.py`): `cal_idx` (2,000) calibration subset; `ev_idx` (11,556) evaluation subset; `keep_<property>` boolean masks for the eight properties, marking the complexes retained by the property-specific gating criterion. |
| `vA_rebuild.npz` | `kept_idx` (90,317): indices, into the intermediate kept space of 90,335, of the complexes retained in the final main domain. |
| `vA_removed_kept.npy` | (18,) int32: positions removed from the 90,335-complex intermediate to obtain the 90,317-complex main domain (generated during the main-domain rebuild; see `gat/build_vA_graphs_local.py`, `gat/rebuild_vA_verbatim.py`). |
| `r5_overlap_idx.npy` | (2,262,) int32: test-set indices involved in the SMILES-overlap sensitivity analysis (`analysis/r5_overlap_sensitivity.py`). |
| `te_match_flags.npy` | (13,547,) int8: per-test-complex element-preserving match flags from the atom-matching survey (`misc/dev_scripts/survey_atom_matching.py`). |
| `te_frac_miss.npy` | (13,547,) float64: per-test-complex fraction of atoms lacking an element-preserving match (`misc/dev_scripts/survey_atom_matching2.py`). |
| `spin_map.json` | `{"spin": {CSD_code: S}, "charge": {CSD_code: q}}` extracted from the released `tmQM_X*.xyz.gz` headers (`analysis/extract_spin.py`). |
| `README_paper_domain_vA.md` | Original notes that accompanied the main-domain build. |
| `retained_ids.csv` | 90,377 retained complexes: `csv_idx, csd_code`. Row number (header excluded) is the **domain index** used by every array in the domain tensors and prediction archives (`repro/review_package_20261021/export_indices.py`). |
| `excluded_ids.csv` | 18,164 excluded records with `reason`: `no_TM` (425), `unparseable_SMILES` (7,383), `isomorphism_failed` (10,356). |
| `atom_maps.npz` | SMILES→XYZ atom maps for all 90,377 records: `csv_idx`, `csd_codes`, `match_src` (matching stage), `n_atoms`, `sm2xyz` (90,377 × 101 int32, padded with −1; `export_atom_maps.py`, RDKit 2024.03.6). |
| `baseline_splits.npz` | SchNet/DimeNet++ split and the baseline three-fold CV: `te_idx` (13,557), `cv_idx` (76,820), `fold_{0,1,2}_{train,val}` (51,213/25,607, 51,213/25,607, 51,214/25,606). |
| `xai_indices.npy` | (2,000,) int64 domain indices: `RandomState(123).choice(90377, 2000, replace=False)`, the perturbation-attribution subset. |
| `ablation_diffs.csv` | 24 rows: `seed, property, r2_uniform, r2_weighted, diff_weighted_minus_uniform` for the corrected metal-weighting ablation. |
| `metal_weight_table.csv` | Main 90,377 cohort, one row per metal: `Z, element, n_m, raw, clipped, normalized`. Re-derived and cross-checked against a SMILES recount by `analysis/verify_metal_weight.py` (the old 30k-subsample script is kept as `analysis/verify_metal_weight_legacy.py`). |
| `metal_weight_summary.csv` | Long-format summary (`cohort, quantity, value`) for the main and ablation cohorts. |
| `metal_weight_reconciliation.json` | The same weight statistics in JSON, including the Pd count and ablation ranges. |
| `tmqmg_pairs.csv` | 73,438 rows: `pred_row, csv_row, id, metal_center, charge, n_atoms, smiles` for the tmQMg transfer set. |
| `tmqmg_reconciliation.json` | tmQMg filter counts, the five unparseable SMILES, and the assertion that `y_true` equals the source CSV columns at the mapped rows. |
| `index_reconciliation.json`, `xai_ablation_reconciliation.json` | Counts, source-file md5 values and cross-checks for the domain construction and the XAI/ablation exports. |
| `catalysts_18_etkdg.sdf`, `catalysts_18_etkdg.json`, `catalysts_etkdg_verification.json` | ETKDG conformers of the 18 case-study catalysts, their metadata and the regeneration check against the published case-study predictions. |

Prediction archives are included under `preds/` (member/ensemble predictions, `y_true`, `te_idx`; `preds/manifest.json` records shapes, dtypes and md5). Molecular graphs and the isomorphism map `new_domain_iso.pt` are regenerated by the scripts in `gat/` and `baselines/`; model checkpoints and the Gaussian logs are distributed as `v1.0-review` GitHub release assets (see `REVIEW_PACKAGE.md`).
