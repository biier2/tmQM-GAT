# Review package: data indices and prediction archives

This directory collects the row-level provenance files, split definitions,
prediction archives and case-study structures that back the numbers reported in
the manuscript and the Supporting Information. Everything here is generated by
the `export_*.py` scripts in this directory from the frozen source artifacts;
nothing is retyped by hand.

All sizes are bytes unless stated otherwise. `MANIFEST.md5` lists the checksum
of every delivered file.

## Index conventions

Three different row indices appear in the project; they are not interchangeable.

| name | meaning |
|---|---|
| `domain index` | 0-based row in the 90,377-complex retained domain, i.e. the row number of `data_indices/retained_ids.csv` after its header. Row order equals ascending `csv_idx`, so `domain index` is also the row order of every array in `new_domain_iso.pt` and of `te_idx`/`cv_idx` in the prediction archives. |
| `csv_idx` | 0-based row in the original `tmQM_y.csv`/XYZ file, 108,541 rows. This is the join key to the public tmQM release. |
| `pred_row` / `csv_row` | tmQMg external validation only: `pred_row` is the 0-based row of the arrays in `crossfunct_A_preds.npz`; `csv_row` is the 0-based row of `tmQMg_properties_and_targets.csv`. |

## Dataset construction chain (main domain)

```
tmQM_y.csv                                   108,541 records
  minus records with no transition metal         425  -> 108,116
  minus records whose SMILES does not parse    7,383  -> 100,733
  minus records whose XYZ/BO matching fails   10,356  ->  90,377
```

The 7,383 unparseable records are counted with the training stack
(RDKit 2024.03.6, empty or unparseable SMILES). The 10,356 failures are the
complement of `new_domain_iso.pt['csv_idx']` inside the 100,733 parseable
records; the VF2++ matching itself is not re-run here. CSD codes agree between
the XYZ headers, `tmQM_y.csv` and `new_domain_iso.pt` for all 90,377 retained
records (0 mismatches).

The main domain file is `new_domain_iso.pt`; the authors' copy is
1,107,170,889 bytes with md5 `3035057aeb8638680d676283ace2194b`. `torch.save`
is not byte-deterministic, so that md5 does not identify a rebuild; use
`repro/verify_domain_content.py` and the content digests in
`repro/domain_content_digests.json`.

### `preds/`

Compressed copies of the eleven prediction archives, verified array-for-array
against the source files (`preds/manifest.json` records shapes, dtypes, sizes
and md5 of both sides).

| file | arrays |
|---|---|
| `test_preds_{A_8d6d,B_8d22d,C_11d6d,D_11d23d,E_9d6d,F_10d6d,G_7d6d,H_7d22d}.npz` | `preds` (9, 13,556, 8), `ens_mean` (13,556, 8), `y_true` (13,556, 8), `te_idx` (13,556,) |
| `test_preds_SchNet.npz` | `preds` (9, 13,557, 8), `ens_mean`, `y_true`, `te_idx` (13,557,) |
| `test_preds_DimeNet.npz` | `preds` (3, 13,557, 8), `ens_mean`, `y_true`, `te_idx` (13,557,) |
| `crossfunct_A_preds.npz` | `preds` (9, 73,438, 7), `ens_mean` (73,438, 7), `y_true` (73,438, 7) |

The eight GAT files use the 13,556-complex test split and their `te_idx` equals
`RandomState(42).permutation(90377)[:13556]` element for element, in order. The
SchNet and DimeNet++ files use the server's 13,557-complex split
(`permutation(90377)[:13557]`), which differs by one complex; the two index
domains are otherwise nested, and `index_reconciliation.json` records both.

`tmqmg_pairs.csv` maps the 73,438 rows of `crossfunct_A_preds.npz` back to
`tmQMg_properties_and_targets.csv`; the five dropped rows are listed in
`tmqmg_reconciliation.json`.

Re-run any script with `python export_<name>.py` from this directory. Paths to
the frozen source artifacts are absolute (`D:\ml\chem_ml5\...`) and are stated
inside each script.

`recompute_tables.py` is the one reviewer-facing check that needs no source
data: it reads the archived predictions and the repository's result JSONs, runs
on CPU in seconds, and returns 0 only if every value matches. Run it from the
repository root:

```bash
python repro/review_package_20261021/recompute_tables.py
```

`MANIFEST.md5` uses the standard `md5sum` two-column format and is checked from
the repository root with `md5sum -c repro/review_package_20261021/MANIFEST.md5`.
The repository's `.gitattributes` forces LF line endings on checkout, so the
checksums are the same on Windows, macOS and Linux.

## Environment

* RDKit 2026.03.3 (main project environment) for `tmqmg_pairs.csv`, the catalyst
  SDF and its verification.
* The parse-status array behind the 7,383 unparseable tmQM records was produced
  with RDKit 2024.03.6, the training stack; its provenance is recorded in
  `index_reconciliation.json` (`rdkit_training_stack`).
* No GPU is required: the catalyst verification runs the nine-member ensemble on
  CPU.

## Known limitations

1. **Corrected-ablation per-metal counts.** The 27,993-complex ablation cohort
   has no persisted per-record index list; its index construction in
   `build_ablation_full.py` cannot be replayed unambiguously. Its verified
   summary (n = 27,993; raw 3.070057–5.0; normalised 0.7343–1.1959; all 27,993
   samples weighted) is delivered in `metal_weight_summary.csv` and
   `metal_weight_reconciliation.json`. The per-metal table is delivered for the
   main 90,377 cohort only.
2. **Catalyst conformers are regenerated, not byte-archived.** ETKDG coordinates
   depend on the RDKit build. The archived SDF is a deterministic regeneration
   of the deployment protocol (seed 42, `maxAttempts=200`) with RDKit 2026.03.3;
   it reproduces the published 3D case-study predictions within 0.0033 eV and
   0.0138 D. The exact build of the production run was not archived; an older
   build available here (RDKit 2024.03.6) gives visibly larger deviations (up to
   0.09 eV and 0.38 D), so the 2026 build is the closer match.
3. **Main-cohort weights are degenerate by construction.** Every transition
   metal in the 90,377-complex domain has `sqrt(N/n_m) > 3.0`, so the clip at 3.0
   flattens all element weights and the mean-normalised sample weight is 1.0 for
   every complex. The ablation cohort is the run in which the weighting is
   non-trivial (clip [0.2, 5.0], 27,993 samples with weight ≠ 1).
